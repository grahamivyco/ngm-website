NATIVE WA GADGET — "Content" (one per group of documents)
=========================================================
This is NOT pasteable into a Custom HTML gadget. These are native Wild
Apricot CONTENT gadgets added in the WA editor, sitting BELOW
01-top.html in the SAME layout row. Nothing goes underneath them.

WHICH GADGET
------------
The RICH-TEXT gadget, named "Content" in the gadget list (the one with
a WYSIWYG toolbar). Custom HTML is what 01-top.html goes into.

Setup in WA:
1. THREE CONTENT GADGETS, in this order (these groups have no year, so
   the cards stay in the order the gadgets sit in):
     Governing documents · Policies · Waivers
2. Select each one → gadget settings → "CSS class" field → enter:
       ngm-wa-docs
3. Set the layout ROW background to transparent, so the linen band
   from 01-top runs continuously behind the cards.

CONTENT — paste each block via the editor's Source / HTML view
---------------------------------------------------------------
Anything after a dash becomes a small chip on the right of the row.

UPDATING A DOCUMENT
-------------------
1. Upload the new PDF via WA → Website → Files.
2. Edit the gadget, select the row's name, re-point the link to the
   new file. Update the date after the dash.
Don't retype a row to move it (retyping loses the link). Cut and paste.

Nothing else goes in these gadgets — no intro copy (that's in
01-top.html), no notes.
